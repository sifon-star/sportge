# SportGym

Сайт фитнес-зала. Статический `index.html` и одна serverless-функция `api/lead.js`,
которая отправляет заявки в Telegram. Сборка не нужна.

## 1. Создай Telegram-бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather), отправь `/newbot` и пройди шаги.
2. Скопируй токен вида `123456789:AA...`.

## 2. Узнай chat_id

**Заявки в личные сообщения:** напиши своему боту любое сообщение (например, `/start`),
затем открой в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates`
и найди `"chat":{"id":123456789,...}`.

**Заявки в группу:** добавь бота в группу, отправь там сообщение, снова открой `getUpdates`.
ID группы начинается с минуса (например, `-1001234567890`).

Несколько получателей указываются через запятую.

## 3. Задеплой на Vercel

1. Залей репозиторий на GitHub, затем на vercel.com: **Add New → Project**.
2. Framework Preset: **Other**. Build Command и Output Directory оставь пустыми.
3. Перед деплоем (или после, в **Settings → Environment Variables**) добавь:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Если переменные добавлены после деплоя, сделай **Redeploy**.

Токен нельзя хранить в коде или в репозитории. Он живёт только в переменных Vercel.

## Как это работает

Форма отправляет `POST /api/lead` с именем и телефоном. Функция проверяет данные,
отсекает ботов (скрытое поле и лимит 5 заявок за 10 минут с одного IP) и шлёт сообщение
через Bot API. Если Telegram недоступен, посетитель увидит ошибку и сможет повторить.

## Проверка

После деплоя отправь заявку с сайта. Если сообщение не пришло, открой в Vercel
**Logs** функции `/api/lead`:
- `not_configured` — не заданы переменные окружения;
- `chat not found` — бот не получал сообщение из этого чата, напиши ему `/start`;
- `Unauthorized` — неверный токен.

## Что заменить перед запуском

Адрес, телефон, почту и цены.
Часовой пояс времени в сообщении по умолчанию `Europe/Moscow`,
меняется переменной `TZ_NAME` (например, `Asia/Yekaterinburg`).
